Mini Arcade · project notes

Three JavaScript prototypes exploring data-driven rules, turn-based state and procedural generation. No package installation or build step is required.

Development and contribution scope

Developed with AI coding assistance, as recorded in the original game commit. Explore the public source, commit history and in-game “How it's built” panels for implementation details.

Inspired by established deckbuilding, poker-roguelite and dungeon-crawler genres; these are browser prototypes, not affiliations with those commercial games.

Bug Slayer

An asynchronous card-battle engine with branching routes, relics and enemy intents.

Implementation: Object-based card and enemy definitions; shared damage calculation; input locking while asynchronous effects resolve; constrained random-walk map generation.

Review route: Start a run, choose a map node, play a card and end the turn. Inspect whether previews match damage and controls unlock after the enemy acts.

Lucky Flush

Poker hand evaluation and an ordered scoring pipeline, with joker hooks and a shop economy.

Implementation: Card grouping plus straight/flush detection, including the ace-low straight; per-card and per-hand joker hooks applied in order; local best-score persistence.

Review route: Start a run, play a hand and inspect Chips × Mult. A robust scoring test should cover ace-low straights, non-scoring kickers and swapped additive/multiplicative joker order.

Neon Crypt

A turn-based dungeon crawler with separate logic and frame rendering.

Implementation: Procedural rooms and connecting corridors; recursive shadowcasting; a shared BFS distance map; canvas lighting and code-defined pixel sprites.

Review route: Start a run, move through a doorway and fight an enemy. Check walls block normal movement and vision, floors connect and the controls respond after each turn.

Run locally

Download a game HTML file and open it in a current browser, or serve the whole repository with python3 -m http.server 8000 and visit http://localhost:8000/mini-arcade/. External fonts are optional; system fonts remain available offline. Scores are stored in the current browser only.

Browser interaction checks cover startup and a short turn sequence. They do not establish complete campaign balance or test every random outcome.
