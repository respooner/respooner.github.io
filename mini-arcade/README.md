# Mini Arcade

三款浏览器小游戏，原本是为游戏编程面试做的作品。每款游戏都是一个独立的 HTML 文件，用原生 JavaScript 写成，不依赖游戏引擎、框架或构建工具；单独下载任意一个文件都能离线玩。

| 游戏 | 类型 | 文件 |
| --- | --- | --- |
| **Bug Slayer** | 卡牌肉鸽（类似杀戮尖塔），程序员主题 | `bug-slayer.html` |
| **Lucky Flush** | 扑克构筑策略肉鸽（类似 Balatro 小丑牌） | `lucky-flush.html` |
| **Neon Crypt** | 回合制地牢探索（霓虹像素风） | `neon-crypt.html` |

`index.html` 是游戏大厅，把三款游戏放在一起介绍；直接打开某个游戏文件也可以。

## 怎么打开

1. 点进想玩的游戏文件（或 `index.html`），再点右上角的下载按钮（Download raw file）。
2. 双击下载好的文件，用 Chrome 或 Edge 打开。想从大厅跳转到各个游戏，就把整个文件夹的文件下载到同一个目录里。

最高分只保存在当前浏览器里。每款游戏右上角的 **ⓘ** 按钮会打开英文版的"How it's built"，面试时可以直接打开讲。

## 面试讲解要点

### 1. Bug Slayer：卡牌肉鸽

**玩法**：你是一名程序员，用"代码卡牌"打 Null Pointer、Memory Leak 等 bug。地图有分支，节点包括普通战斗、精英、商店、随机事件和咖啡休息点；打败 Boss（Legacy Monolith）后进入更难的下一幕，可以无限挑战。

**可以讲的技术点**
- **数据驱动**：卡牌、敌人、遗物、事件都是普通对象（`CARDS` / `FOES` / `RELICS` / `EVENTS`），新增一张卡只要加一行，奖励池和商店会自动收录。
- **伤害管线**：`(基础伤害 + 力量) × 虚弱 × 易伤`，再扣格挡。卡牌上显示的数字和敌人意图都调用同一个函数预览，所以玩家看到的数字就是实际结算的数字。
- **异步回合引擎**：出牌效果和敌人回合都是 `async` 函数，中间用 `await sleep()` 控制动画节奏，同时锁住输入。
- **程序化地图**：4 条随机游走路径从底部往上走，如果某一步会和已有的边交叉就换一个方向，所以路线不会交叉。房间类型按权重抽取，同时有规则约束（前几层不出精英、Boss 前固定是休息点）。
- **敌人意图**：AI 是"回合数 → 行动"的纯函数，下一回合要做什么会提前显示出来，方便平衡数值。

### 2. Lucky Flush：扑克策略肉鸽

**玩法**：打出扑克牌型得到"筹码 × 倍率"，分数要超过盲注目标。用钱买小丑牌（改变计分规则）、牌型升级书和永久升级。共 8 个底注（Ante），每个底注的 Boss 盲注都带一个限制效果，打通后进入无尽模式。

**可以讲的技术点**
- **牌型判定**：先按点数分组，再按组大小排序；同花和顺子（包括 A-2-3-4-5）单独判断。返回值包含牌型和"哪几张牌计分"，所以不计分的踢脚牌不加筹码。
- **计分管线**：`(牌型筹码 + 计分牌筹码 + 小丑筹码) × (牌型倍率 + 小丑加倍率) × 小丑乘倍率`。因为先加后乘，小丑牌的**排列顺序**会影响最终分数，这是游戏的核心策略之一。
- **钩子式小丑牌**：每张小丑牌是"数据 + 可选钩子函数"：`card()` 在每张计分牌上触发，`hand()` 每手牌触发一次，`cash()` 在回合结束时触发。引擎本身不认识任何一张具体的小丑牌。
- **计分动画**：计分循环里每一步都 `await` 一小段时间，所以数学计算和动画展示是同一段代码；速度按钮只是缩放这些延时。
- **经济系统**：利息规则是每持有 $5 得 $1（有上限），刷新商店的价格会逐次上涨。花钱还是存钱，是玩家要反复权衡的问题。

### 3. Neon Crypt：地牢探索

**玩法**：每层地牢都是随机生成的。靠提灯照明探索，撞向怪物即可攻击，拾取药水和卷轴；每次升级三选一天赋，每 5 层有一个巫妖 Boss。

**可以讲的技术点**
- **程序化地牢**：随机放置互不重叠的房间，按顺序用 L 形走廊连接，再额外加几条连接形成环路。楼梯放在离起点"步行距离"最远的房间（用 BFS 计算）。
- **视野（FOV）**：用递归阴影投射（recursive shadowcasting）分 8 个八分区计算；去过的格子会被记住，并以暗色显示（战争迷雾）。
- **共享寻路**：每回合从玩家位置做一次 BFS，得到一张距离图（Dijkstra map）。所有怪物只需走向距离更小的相邻格，开销是 O(地图大小) 一次，而不是每只怪各跑一次 A*。幽灵可以穿墙，蝙蝠每回合移动两次且路线随机。
- **动态光照**：在离屏 canvas 上画一层黑暗，用 `destination-out` 给提灯和火把挖出径向渐变的"光洞"，再用 `lighter` 混合模式叠一层暖色光晕。
- **代码像素画**：精灵是 8×8 的字符串加调色板，启动时烘焙成小 canvas（另外烘焙一份纯白版本用于受击闪白），关闭平滑后放大绘制。
- **回合与帧分离**：游戏逻辑严格按回合、按格子坐标运行；渲染每帧执行，把位置、攻击前冲、粒子、飘字缓动到逻辑状态。
